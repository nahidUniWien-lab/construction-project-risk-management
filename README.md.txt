# Construction Project Risk Management – Business Analysis Case Study

## Project Objective

This project demonstrates how business analysis techniques can support the development of a project risk management software solution.

The goal was to identify project risks related to cost overruns, delays and open issues.

## Business Problem

Project managers need a simple way to identify risky projects and take action early.

## What I Did

- Defined business and functional requirements
- Created an AS-IS and TO-BE process model
- Developed user stories and acceptance criteria
- Created and prioritised a product backlog
- Performed manual acceptance testing
- Built a simple Power BI risk dashboard
- Analysed project cost and schedule risks
